# Welcome to mdcat

Markdown worth reading, right in your terminal. Try **bold**,
_emphasis_, ~~strikethrough~~, and `inline code`.

## A little structure

- Notes
  - Ideas worth returning to
  - Details that belong together
- Small tools
- Room to think

Read the [guide](https://example.com/guide), or visit
<https://example.com> directly.

### Code with room to breathe

```rust
fn main() {
    println!("Hello, terminal!");
}
```

### A little perspective

> Good tools make everyday work easier.
> They also keep the small details intact.  
> Especially when a line break matters.

### At a glance

| Feature | What you get |
| :--- | :--- |
| Prose | Wrapping at your chosen width |
| Code | Syntax colors, intact lines |
| Links | Visible destinations and optional clicks |
| Pipes | Plain text by default |

---

#### Notes

Images have useful placeholders: ![A mountain at dawn](mountain.png).
Footnotes keep their labels and content.[^detail]

[^detail]: This is a terminal reader, so raw HTML and actual images
    are left to a browser.

##### Small details

Punctuation stays as written: "quotes", -- dashes, and ... dots.

###### The end

Readable text, without leaving the shell.
